১. সারসংক্ষেপ ও প্রকল্প পরিচিতি

Smart StudyMate হলো শিক্ষার্থীদের জন্য তৈরি একটি mobile-first study assistant। অ্যাপটি ক্লাস রুটিন, পড়ার পরিকল্পনা, Pomodoro focus timer, অগ্রগতি দেখা এবং সহপাঠীদের সঙ্গে friend request ও live messaging একত্র করে।

এই প্রকল্পের লক্ষ্য হলো বিচ্ছিন্ন পড়াশোনার কাজকে একটি সহজ ইন্টারফেসে আনা এবং শিক্ষার্থীদের পারস্পরিক সহযোগিতার সুযোগ তৈরি করা। ব্যবহারকারী account খুলে সাইন ইন করতে পারবেন। সার্ভার শিক্ষার্থীর account, বন্ধু সম্পর্ক এবং message সংরক্ষণ করবে। প্রশাসক account registration ও গুরুত্বপূর্ণ activity পর্যবেক্ষণ করতে পারবেন; ব্যক্তিগত message-এর লেখা admin activity log-এ প্রকাশ করা হবে না।

সমস্যার বিবরণ

শিক্ষার্থীরা প্রায়ই রুটিন, পড়ার কাজ, সময় ব্যবস্থাপনা এবং সহপাঠীর সঙ্গে যোগাযোগের জন্য একাধিক মাধ্যম ব্যবহার করে। এতে কাজ ছড়িয়ে যায় এবং অগ্রগতি ধরে রাখা কঠিন হয়। নিরাপদ account ও তথ্য সংরক্ষণ ছাড়া কেবল browser-ভিত্তিক prototype-এ একাধিক শিক্ষার্থীর মধ্যে বাস্তব যোগাযোগ সম্ভব নয়।

প্রকল্পের লক্ষ্য

  • মোবাইল স্ক্রিনে সহজে ব্যবহারযোগ্য শিক্ষার্থী সহায়ক অ্যাপ তৈরি করা।
  • account registration, sign-in ও sign-out-সহ server-backed পরিচয় ব্যবস্থাপনা করা।
  • বন্ধু খোঁজা, অনুরোধ পাঠানো ও গ্রহণ করার সুবিধা দেওয়া।
  • বন্ধুদের মধ্যে message পাঠানো এবং live delivery দেখানো।
  • admin dashboard-এ account ও activity সম্পর্কে সংক্ষিপ্ত তথ্য দেখানো।
  • Android APK হিসেবে অ্যাপটি install ও প্রদর্শনযোগ্য করা।

প্রস্তাবিত ফলাফল

একটি Android installable app, একটি REST/WebSocket backend, SQLite database এবং admin view—যা demo environment-এ account ও student-to-student communication দেখাতে পারবে।

২. পরিধি ও প্রধান ফিচার

পড়াশোনার সহায়তা

  • সাপ্তাহিক class routine ও বিষয়ভিত্তিক schedule view
  • Study planner ও task/checklist interface
  • ২৫/৫০ মিনিটের Pomodoro focus timer
  • সাপ্তাহিক study progress summary view
বর্তমান UI-তে কিছু sample/demo তথ্য

Account ও যোগাযোগ

  • নাম, email, department ও batch দিয়ে student registration
  • সাইন ইন, session token ও sign-out
  • শিক্ষার্থী search ও friend request
  • অনুরোধ গ্রহণ/প্রত্যাখ্যান এবং বন্ধু তালিকা
  • বন্ধুদের মধ্যে persisted message ও live WebSocket delivery

Admin সুবিধা

  • Admin sign-in ও role-protected dashboard
  • মোট registration, department/batch ও account তালিকা
  • শেষ sign-in ও message count-এর মতো activity summary
  • account, login, friend request ও message event log

গোপনীয়তার জন্য admin log-এ message-এর মূল লেখা থাকে না।

নিরাপত্তা ও সংরক্ষণ

  • Password bcrypt hash আকারে সংরক্ষণ
  • Token-ভিত্তিক session authentication
  • Registration/login rate limit ও input validation
  • SQLite foreign key ও persistent database file
  • Public deployment-এর জন্য HTTPS ও শক্তিশালী admin secret নির্ধারণ

ব্যবহারকারী ভূমিকা

ভূমিকাকাজসীমা
Studentনিজের account, বন্ধু, request ও conversation ব্যবহারশুধু নিজের অনুমোদিত তথ্য ও বন্ধুদের সঙ্গে conversation
Adminনিবন্ধন ও activity পর্যবেক্ষণশিক্ষার্থীর private message body dashboard log-এ দেখানো হয় না

৪. কাজের পদ্ধতি, পরীক্ষা ও পরিকল্পনা

উন্নয়ন পদ্ধতি

  1. প্রয়োজন নির্ধারণ ও app flow সাজানো।
  2. Mobile-first interface ও local navigation তৈরি।
  3. Database schema, API এবং authentication যুক্ত করা।
  4. Friend request, friendship ও messaging flow সংযুক্ত করা।
  5. Admin dashboard ও audit event যুক্ত করা।
  6. Android build, integration check এবং demo প্রস্তুত করা।

সীমাবদ্ধতা ও ভবিষ্যৎ কাজ

  • এ মুহূর্তে public hosting/domain যুক্ত নেই; server local/demo অবস্থায়।
  • Routine, planner, progress, institution resource ও community-এর কিছু অংশ sample/demo data ব্যবহার করে।
  • Production-এর আগে HTTPS hosting, backup/restore, monitoring, privacy notice এবং বাস্তব user acceptance test দরকার।
  • পরবর্তী সংস্করণে real institution schedule, notification, moderation/reporting, stronger account recovery এবং richer progress analytics যোগ করা যেতে পারে।
উপসংহার: Smart StudyMate শিক্ষার্থীর পরিকল্পনা ও peer collaboration এক অ্যাপে আনার একটি বাস্তবসম্মত prototype। Android client, Node.js API এবং SQLite persistence দিয়ে account, friendship, live chat ও admin oversight-এর end-to-end ধারণা প্রদর্শন করা যায়।
